🤖 Así funciona nuestro modelo

1️⃣ Nivel real

Primero medimos el rendimiento de cada equipo utilizando puntos anotados y puntos permitidos.

Pythagorean = PF^2.37 / (PF^2.37 + PA^2.37)

La fórmula Pythagorean se utiliza aquí como adaptación del modelo original a NFL.

2️⃣ Cruce de equipos

Después comparamos la fuerza de ambos equipos mediante Log5.

P = (A − A×B) / (A + B − 2×A×B)

3️⃣ Localía

La probabilidad neutral se convierte en una probabilidad final aplicando una ventaja de local.

Odds finales = Odds neutrales × (0.54 / 0.46)

4️⃣ Puntos proyectados

El modelo combina la producción ofensiva de un equipo con los puntos que permite su rival.

Para evitar depender únicamente de una muestra pequeña, se utilizan: 50% temporada + 35% últimos 10 + 15% primeros 3.

5️⃣ Spread

Se utiliza la diferencia de puntos proyectada para estimar la probabilidad de que el favorito cubra -1.5.

6️⃣ Pick del modelo

Finalmente se comparan las probabilidades de:

  • Local ML
  • Visitante ML
  • Over
  • Under
  • Favorito -1.5
  • Underdog +1.5
⚠️ Este es un modelo matemático. No incorpora automáticamente lesiones, jugadores inactivos, clima, matchups específicos, coaching, cambios de QB u otras variables externas. Una probabilidad alta no garantiza que una apuesta gane.
